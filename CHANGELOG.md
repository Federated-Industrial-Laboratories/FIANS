# Changelog

## 0.1.0

- Add the FIANS command for local rendering, desktop playback and worker control.
- Package Praetor as a clean reference and separate sound treatment.
- Pin Chatterbox Nano weights by revision and per-file SHA256 hashes.
- Support explicit model downloads and registration of existing verified files.
- Provide a private CPU runtime installer and source-independent launcher.
- Add source and wheel packaging, component notices and operator manuals.

The initial interface targets English narration on Linux x86-64 with Python 3.12.
The base model remains upstream Chatterbox Nano; Praetor is a voice profile.
